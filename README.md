# WatchTogether

موقع مشاهدة جماعية لفيديوهات YouTube باستخدام Node.js وSocket.IO.

## التشغيل على جهازك
1. ثبّت Node.js (إصدار LTS).
2. فك ضغط المشروع وافتح Terminal داخل مجلد المشروع.
3. نفّذ:
   ```bash
   npm install
   npm start
   ```
4. افتح http://localhost:3000

## التجربة مع أشخاص من أماكن مختلفة
لازم تنشر المشروع على استضافة تدعم Node.js وWebSockets (مثل Render أو Railway أو VPS)، ثم تشارك رابط الموقع.
لا يكفي تشغيله على localhost؛ localhost متاح لجهازك فقط.

## ملاحظات
- الغرف محفوظة في ذاكرة السيرفر مؤقتًا، وتختفي عند إعادة تشغيله أو عند خروج الجميع.
- المضيف وحده يضيف/يغيّر فيديو يوتيوب. صلاحية المضيف تنتقل لأول عضو متبقٍ إذا خرج.
- كل الأعضاء يمكنهم التشغيل والإيقاف والتقديم، لذلك قد تتعارض أوامرهم إذا ضغطوا في نفس اللحظة.
- المزامنة تقريبية وقد تتأثر بسرعة الإنترنت والتحميل.
- بعض فيديوهات YouTube تمنع التضمين أو تتطلب تسجيل دخول/تأكيد عمر؛ الموقع لا يتجاوز قيود YouTube.
- استخدم الفيديوهات التي يحق لك مشاهدتها وشارك روابطها فقط.
- هذه نسخة أولية بدون حسابات مستخدمين أو تخزين دائم أو حماية متقدمة من الإساءة.
